Hướng dẫn Docker Cơ bản cho Lập trình viên PHP

Phiên bản 1.0 (Bản gốc ban đầu). Docker giúp đóng gói ứng dụng PHP cùng toàn bộ môi trường thực thi vào một container nhẹ và nhất quán.

1. Dockerfile cơ bản cho PHP-FPM

Tạo tệp Dockerfile để định nghĩa hệ điều hành nền tảng và cài đặt các phần mở rộng PHP cần thiết:

FROM php:8.2-fpm
RUN apt-get update && apt-get install -y libpq-dev \
    && docker-php-ext-install pdo pdo_pgsql

2. Lợi ích của Container hóa

Loại bỏ hoàn toàn vấn đề "chạy được trên máy tôi nhưng lỗi trên máy bạn". Môi trường phát triển và môi trường máy chủ sản xuất hoàn toàn giống hệt nhau.
