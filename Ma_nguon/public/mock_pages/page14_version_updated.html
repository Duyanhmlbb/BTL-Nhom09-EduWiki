Hướng dẫn Docker Cơ bản cho Lập trình viên PHP

Phiên bản 2.0 (Bản cập nhật mở rộng). Docker giúp đóng gói ứng dụng PHP cùng toàn bộ môi trường thực thi vào một container nhẹ và nhất quán.

1. Dockerfile cơ bản cho PHP-FPM

Tạo tệp Dockerfile để định nghĩa hệ điều hành nền tảng và cài đặt các phần mở rộng PHP cần thiết:

FROM php:8.2-fpm
RUN apt-get update && apt-get install -y libpq-dev \
    && docker-php-ext-install pdo pdo_pgsql

2. Quản lý Đa Container với Docker Compose (Bổ sung mới)

Trong phiên bản 2.0 này, chúng ta kết hợp ứng dụng PHP với Nginx web server và cơ sở dữ liệu PostgreSQL qua tệp docker-compose.yml tiện lợi:

version: '3.8'
services:
  web:
    image: nginx:alpine
    ports:
      - "8080:80"
  db:
    image: postgres:15
    environment:
      POSTGRES_PASSWORD: secret

3. Lợi ích khi cập nhật phiên bản

Khi Wiki Archiver phát hiện hoặc người dùng bấm lấy bản mới, hệ thống sẽ lưu bản này thành Snapshot phiên bản 2 nhưng vẫn giữ nguyên Snapshot phiên bản 1 trước đó để so sánh đối chiếu.
