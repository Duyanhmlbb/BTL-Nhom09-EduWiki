Hướng dẫn sử dụng PostgreSQL và PDO trong PHP

PostgreSQL là hệ quản trị cơ sở dữ liệu quan hệ mã nguồn mở mạnh mẽ nhất hiện nay, hỗ trợ đầy đủ SQL chuẩn và nhiều tính năng nâng cao.

1. Kết nối PostgreSQL bằng PDO

PHP Data Objects (PDO) cung cấp interface thống nhất để kết nối nhiều loại cơ sở dữ liệu khác nhau, bao gồm PostgreSQL.

$dsn = "pgsql:host=127.0.0.1;port=5432;dbname=mydb";
$pdo = new PDO($dsn, 'username', 'password', [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]);

2. Truy vấn an toàn với Prepared Statements

Prepared statements là cách hiệu quả nhất để chống tấn công SQL Injection. Luôn sử dụng tham số ràng buộc thay vì nối chuỗi trực tiếp.

$stmt = $pdo->prepare("SELECT * FROM users WHERE username = ? AND active = ?");
$stmt->execute([$username, true]);
$user = $stmt->fetch();

3. Transaction và ACID

PostgreSQL hỗ trợ đầy đủ thuộc tính ACID (Atomicity, Consistency, Isolation, Durability) thông qua transaction. Đây là yếu tố quan trọng đảm bảo tính toàn vẹn dữ liệu.

4. Full-Text Search trong PostgreSQL

PostgreSQL có hỗ trợ tìm kiếm toàn văn bản (full-text search) mạnh mẽ với kiểu dữ liệu tsvector và tsquery. Có thể tích hợp từ điển tiếng Việt để tìm kiếm hiệu quả hơn.

Nắm vững PostgreSQL và PDO sẽ giúp bạn xây dựng ứng dụng web backend mạnh mẽ, an toàn và hiệu suất cao.
