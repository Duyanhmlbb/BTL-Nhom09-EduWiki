Hướng dẫn Lập trình Hướng đối tượng OOP trong PHP

Lập trình hướng đối tượng (Object-Oriented Programming - OOP) là một mô hình lập trình mạnh mẽ được áp dụng rộng rãi trong PHP và nhiều ngôn ngữ hiện đại khác.

1. Các khái niệm cốt lõi

OOP xoay quanh bốn khái niệm chính: đóng gói (encapsulation), kế thừa (inheritance), đa hình (polymorphism) và trừu tượng (abstraction).

2. Lớp và Đối tượng

Lớp (class) là bản thiết kế (blueprint) để tạo ra các đối tượng (object). Một đối tượng là thể hiện (instance) cụ thể của một lớp.

class Animal {
    protected string $name;
    public function __construct(string $name) {
        $this->name = $name;
    }
    public function speak(): string {
        return "{$this->name} nói gì đó.";
    }
}

class Dog extends Animal {
    public function speak(): string {
        return "{$this->name} nói: Gâu gâu!";
    }
}

$dog = new Dog("Milo");
echo $dog->speak(); // Milo nói: Gâu gâu!

3. Đa hình (Polymorphism)

Đa hình cho phép các đối tượng thuộc các lớp khác nhau phản hồi cùng một thông điệp theo cách riêng của chúng. Đây là tính năng cốt lõi giúp code linh hoạt và dễ mở rộng.

4. Interface và Abstract Class

Interface định nghĩa hợp đồng mà các lớp phải thực thi. Abstract class cung cấp một bộ khung chung cho các lớp con.

Lập trình hướng đối tượng giúp tổ chức code rõ ràng, tái sử dụng được và dễ bảo trì. Đây là kỹ năng không thể thiếu cho bất kỳ lập trình viên PHP chuyên nghiệp nào.
